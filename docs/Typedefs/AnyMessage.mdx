> Represents a message from **any supported Discord library**.

> This type is designed for library-agnostic interoperability —  
> allowing you to handle messages from different client frameworks  
> such as Discord.js, Oceanic.js, Detritus, Eris, or Seyfert.

```ts
type AnyMessage = 
  | PortableMessage 
  | DJSMessage 
  | OceanicMessage 
  | DetritusMessage 
  | ErisMessage 
  | SeyfertMessage;
```
