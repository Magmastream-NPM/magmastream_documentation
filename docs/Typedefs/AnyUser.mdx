> Represents a user from **any supported Discord library**.

> This type is designed for library-agnostic interoperability —  
> allowing you to handle users from different client frameworks  
> such as Discord.js, Oceanic.js, Detritus, Eris, or Seyfert.

```ts
type AnyUser =
  | DJSUser
  | DJSClientUser
  | OceanicUser
  | DetritusUser
  | ErisUser
  | SeyfertUser
  | SeyfertClientUser;
```
